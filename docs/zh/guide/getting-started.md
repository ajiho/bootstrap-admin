# 快速开始

## 安装

您可以通过以下任意一种方式获得 AdminLTS :

### Git 下载(推荐)

您也可以通过 GitHub 或 Gitee 的 [releases](https://github.com/ajiho/AdminLTS/releases) 列表下载。

### 包管理器

::: code-group

```sh [npm]
$ npm add -D adminlts
```

```sh [pnpm]
$ pnpm add -D adminlts
```

```sh [yarn]
$ yarn add -D adminlts
```

```sh [bun]
$ bun add -D adminlts
```

```sh [composer]
$ composer require ajiho/adminlts
```

:::
